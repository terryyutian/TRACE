TRACE
Text Revision Analysis via Change Estimation

About

This is a demo web app for TRACE, an automated approach for multi-granularity analysis of textual revisions between a source text and a target text.

How to use

  1. Paste your draft into Source Text.
  2. Paste your revised version into Target Text (or paste the source and edit).
  3. Click Analyze Text Changes.
